# assets/front_shiny

Shiny **front** (enemy) sheets. Same naming as `assets/front`.

Sources: the pack's `Graphics/Pokemon/Front shiny/` folder. Stems are e.g.
`ABOMASNOW.png`, `CHARIZARD_1.png`, `ABOMASNOW_female.png`.

To fill this folder (and the other three) up front, run
`python3 ../download_assets.py` from this folder.
