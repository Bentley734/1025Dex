# Cry styles

Anime: user-supplied Real PKMN Cries 1.0 by Galladito (RealCries.zip). The 649 numbered WAVs are encoded to Ogg Vorbis for playback. Missing clips use CURRENT cries.

Showdown: https://play.pokemonshowdown.com/audio/cries/ — Pokemon Showdown cry collection; Pokemon audio belongs to its original rights holders. National-number mapping uses PokeAPI species identifiers. All 1025 base species are included.

Downloaded clips retain their original Showdown audio bytes. See CRY-STYLES-AUDIT.json for hashes. No audio is fetched during battle.

POKEAPI selects the latest numbered cries from https://github.com/PokeAPI/cries. All 1025 clips match existing CURRENT packed audio, so asset pack 1.1.0 is reused. Unlike CURRENT, POKEAPI uses the packed Pikachu cry in Yellow. Repository license: POKEAPI-CRIES-LICENSE.txt.
